# PICT

## Назначение

`pict` помогает применять попарное тестирование. Инструмент строит сокращенный набор тестовых комбинаций так, чтобы покрыть все пары значений параметров без полного перебора всех вариантов.

## Входные данные

- Модель описывается в текстовом файле.
- Пример входного файла лежит в корне репозитория: `pict_example.txt`.
- В примере параметры задаются списками значений, а ограничения оформляются через `if`.

## Запуск

Из корня проекта выполните:

```bash
podman run -it --rm -v ./:/var/pict:Z pict:latest pict_example.txt
```

## Результат

Команда выводит в консоль набор тестовых комбинаций, сокращенный за счет попарного покрытия.
