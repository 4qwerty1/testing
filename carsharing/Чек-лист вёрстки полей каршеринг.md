# Чек-лист на вёрстку полей и элементов карты

## Общие условия

- [ ] В форме бронирования по умолчанию выбран тариф «Повседневный».
- [ ] Если макет и требования расходятся, в интерфейсе реализован вариант из требований.
- [ ] Все тексты, подписи, заголовки и кнопки написаны без орфографических ошибок.
- [ ] Левый блок формы, карта и всплывающие окна не наезжают друг на друга, элементы выровнены и не обрезаются.

## Форма бронирования

### Шапка формы и адресные поля

- [ ] В форме отображаются поля «Откуда» и «Куда», заполненные в верхней части левой панели.
- [ ] У каждого адресного поля есть цветной маркер слева, текст адреса внутри поля и иконка удаления справа.
- [ ] Иконка возврата назад со стрелкой влево расположена над блоком тарифов и визуально отделена от адресных полей.
- [ ] При удалении одного или обоих адресов вёрстка формы не ломается: блоки ниже не смещаются и не перекрываются.

### Выбор тарифа «Повседневный»

- [ ] В панели тарифов отображаются три карточки: «Повседневный», «Походный», «Роскошный».
- [ ] У каждой карточки тарифа есть иконка автомобиля, название тарифа и цена.
- [ ] Карточка тарифа «Повседневный» по умолчанию выделена серым фоном как выбранная.
- [ ] Неактивные тарифы визуально отличаются от выбранного и не выглядят выбранными одновременно.

### Карточка выбранной машины для тарифа «Повседневный»

- [ ] Под тарифами отображается карточка машины выбранного тарифа.
- [ ] В карточке машины для тарифа «Повседневный» указана марка BMW 750.
- [ ] В карточке отображается заголовок «Просто по делам, ничего лишнего».
- [ ] В подзаголовке отображается время в пути до машины в формате «n мин» и текст «15 мин бесплатного ожидания».
- [ ] Если адрес в поле «Откуда» удалён, время в пути до машины в карточке не отображается.
- [ ] В карточке отображается изображение автомобиля.
- [ ] В карточке отображаются фичи «видеорегистратор» и «зарядка для телефона».
- [ ] Тексты в карточке машины не выходят за границы блока и не перекрывают изображение.

### Поле «Добавить права» / «Права»

- [ ] По умолчанию на форме отображается незаполненное поле «Добавить права».
- [ ] Поле расположено отдельным блоком под карточкой машины и над полем «Способ оплаты».
- [ ] В незаполненном состоянии поле содержит только текст «Добавить права» и иконку перехода справа.
- [ ] После успешной верификации поле меняет подпись на «Права».
- [ ] После успешной верификации поле имеет зелёную рамку.
- [ ] После успешной верификации внутри поля справа отображается зелёная галочка.
- [ ] После неуспешной верификации поле имеет красную рамку.
- [ ] После неуспешной верификации внутри поля справа отображается красный крестик.
- [ ] В состоянии ожидания результата после отправки документов в поле отображается таймер на 30 секунд.
- [ ] В каждом состоянии содержимое поля выровнено по вертикали, иконки не прилипают к краям и не искажаются.

### Поле «Способ оплаты»

- [ ] По умолчанию поле «Способ оплаты» отображается незаполненным.
- [ ] Если карта не привязана, в поле вместо слова «Карта» отображается слово «Добавить».
- [ ] В незаполненном состоянии в поле есть подпись «Способ оплаты», текст состояния и иконка карты.
- [ ] После выбора карты поле заполняется данными выбранной карты.
- [ ] После выбора карты в поле отображается слово «Карта» и последние 4 цифры номера карты.
- [ ] Текст, последние 4 цифры карты, иконка карты и стрелка перехода не перекрывают друг друга.
- [ ] Поле «Способ оплаты» визуально отделено от поля «Права» и кнопки бронирования.

### Панель «Требования к заказу» для тарифа «Повседневный»

- [ ] Для тарифа «Повседневный» панель «Требования к заказу» по умолчанию свёрнута.
- [ ] В свёрнутом состоянии панель не занимает лишнее место и не нарушает расстояния между блоками.
- [ ] Содержимое панели для тарифа «Повседневный» соответствует требованиям: чекбокс «Зарядка для телефона» и действие для «Светомузыка» с указанием доступности в тарифе «Роскошный».
- [ ] Если панель раскрыта, элементы внутри выровнены, подписи читаемы, а скролл отображается корректно.

### Кнопка «Забронировать»

- [ ] Кнопка закреплена в левом нижнем углу экрана.
- [ ] Кнопка по ширине совпадает с колонкой формы и не выходит за её пределы.
- [ ] В состоянии без прав кнопка содержит текст «Добавить права и забронировать».
- [ ] В состоянии без способа оплаты кнопка содержит текст «Добавить оплату и забронировать».
- [ ] При заполненных обязательных полях кнопка содержит текст «Забронировать».
- [ ] Если адреса заполнены, под основным текстом кнопки отображается строка маршрута в формате «Маршрут составит .. км и займет .. мин».
- [ ] Если адреса удалены, на кнопке остаётся только текст действия без строки маршрута.
- [ ] Текст кнопки выровнен по центру, не обрезается и помещается в одну или две аккуратные строки по макету.

## Всплывающие окна

### Сообщение после отправки прав на проверку

- [ ] После отправки данных прав отображается модальное окно с текстом «Спасибо! Документы отправлены на проверку. Скоро расскажем о результатах».
- [ ] В модальном окне отображается кнопка «Принято» / «Понятно» согласно реализованному сценарию, текст кнопки написан без ошибок и центрирован.
- [ ] Модальное окно расположено по центру экрана, фон под ним затемнён.

### Окно «Машина забронирована»

- [ ] Окно «Машина забронирована» отображается по центру экрана поверх затемнённой карты.
- [ ] В окне есть заголовок «Машина забронирована».
- [ ] В верхней части окна отображается блок бесплатного ожидания с таймером.
- [ ] В окне отображаются марка и номер машины.
- [ ] В окне отображается изображение машины.
- [ ] В окне отображается адрес машины.
- [ ] В окне отображается стоимость поездки; при заполненных адресах показывается точная стоимость, без адресов — стоимость за минуту.
- [ ] В окне есть заметное действие отмены поездки.
- [ ] Все элементы окна выровнены, иконки и текст не перекрываются.

### Окно «Вы уверены, что хотите отменить поездку?»

- [ ] После запуска отмены отображается модальное окно с текстом «Вы уверены, что хотите отменить поездку?».
- [ ] В окне отображаются две кнопки: «Нет» и «Да».
- [ ] Кнопки визуально различаются по цвету и состояниям, подписи в них читаемы.
- [ ] Текст вопроса центрирован и не выходит за границы окна.

### Окно «Поездка отменена»

- [ ] После подтверждения отмены отображается модальное окно с текстом «Поездка отменена».
- [ ] В окне отображается кнопка подтверждения «Принято».
- [ ] Окно расположено по центру, затемнение фона сохраняется до закрытия окна.

## Элементы на навигационной карте

### Иконки автомобилей

- [ ] На карте отображаются иконки свободных автомобилей.
- [ ] На карте одновременно отображаются автомобили всех тарифов, а не только «Повседневного».
- [ ] Иконки автомобилей не размыты, не деформированы и не перекрывают важные элементы карты без необходимости.
- [ ] Иконки автомобилей повернуты и выглядят как автомобильные маркеры, а не как стандартные pin-иконки.

### Ближайшая и выбранная машина

- [ ] Система автоматически выделяет ближайшую машину.
- [ ] Иконка ближайшей машины увеличена относительно остальных.
- [ ] Над ближайшей машиной отображается чёрная плашка с маркой машины.
- [ ] Текст марки внутри чёрной плашки читаем, выровнен по центру и не выходит за её границы.
- [ ] При выборе другой машины на карте выбранная иконка увеличивается.
- [ ] При выборе другой машины над ней также появляется чёрная плашка с маркой.
- [ ] После выбора другой машины информация о машине в левой панели обновляется под выбранный автомобиль.
- [ ] В любой момент только одна машина отображается как выбранная.

### Действия с картой и машиной

- [ ] Пользователь может выбрать машину нажатием на её иконку на карте.
- [ ] После выбора машины остальные иконки сохраняют обычный размер и не получают плашку с маркой.
- [ ] Масштаб карты и кнопки zoom не перекрывают иконки машин и чёрную плашку выбранной машины.
- [ ] Маршрут и адресные маркеры A/B остаются читаемыми после выбора машины.
- [ ] Иконки машин, плашка с маркой и маршрут не наезжают на левую панель формы.
